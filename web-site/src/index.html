Local files, browser tools

Choose one file at a time. We read its contents in this browser, without uploading it or saving a document history. Refreshing or closing the tab clears the current file; choose it again to continue.

Offline: Enable offline while connected to save the app and its libraries. Your documents are never added to that cache. Browser storage can be cleared or evicted. A first visit and app updates need a connection.

Install: In a supported desktop Chrome or Edge browser, use Install app or the browser’s install menu. File-handler support depends on the browser and your permissions. After installation, check Windows “Open with” and choose your default if offered. This integration has not yet been verified on your PC.

Reading limits: Word and EPUB are simplified reading views. Excel shows saved values without recalculation. EPUB encryption and fixed layout, animated images, macros and external resources are unsupported. Tables show a navigable window of rows. PDF prints a bounded range; EPUB prints the current chapter.

Size limits: PDF 150 MiB; DOCX/XLSX 12 MiB; text 8 MiB; Markdown 2 MiB; other supported files 24 MiB. ZIP expansion, image pixels, cells and processing time have additional limits. These are not a total-browser-memory guarantee.
